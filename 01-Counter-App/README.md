# React Counter Application

## 📌 Project Overview

The Counter Application is a beginner-friendly project developed using React.js. It allows users to increase, decrease, and reset a counter value.

Users can also customize the step count to control how much the counter value changes with each button click.

This project is created for learning React fundamentals and understanding state management and event handling.

## ✨ Features

- Increment Counter (+)
- Decrement Counter (-)
- Reset Counter to Zero
- Custom Step Count
- Prevents Counter from Going Below Zero
- Responsive User Interface

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- Bootstrap 5

## 📚 React Concepts Learned

1. Functional Components
2. useState Hook
3. Event Handling (onClick, onChange)
4. Controlled Components
5. State Management
6. JSX
7. JavaScript Functions and Arrow Functions
8. Conditional Logic using Math.max()

## ⚙️ How It Works

- Initially, the counter value is 0.
- The default step count is 1.
- Clicking the + button increases the counter.
- Clicking the - button decreases the counter.
- The counter cannot go below 0.
- Clicking Reset sets the counter back to 0.
- Users can customize the step count using the number input field.
